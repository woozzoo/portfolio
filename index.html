카스파

세차 매장의 키오스크, 사용자 앱, 파트너·관리자 어드민을 한 서비스로 설계했다.

기간
2023.09 ~ 2025.01
결과
실제 매장 운영 중 · 앱 스토어 출시

PROBLEM

고객사는 세차 매장 서비스에 앱 예약과 이용권 판매를 원했다.

DECISION

예약권과 회차권의 결제 흐름을 나눴다. 키오스크는 현장에서 빨리 끝나도록 선택 단계를 줄였고, 컨셉은 고객 요청과 브랜드 방향에 맞춰 v1에서 v2로 바꿨다.

OUTCOME

고객 승인·납품, 앱 스토어 출시, 실제 매장 운영 중. 기획·디자인은 혼자 맡았다.

PROCESS

01

흐름 설계

회원가입·로그인, 세차권 구매·예약, 차량 등록, 선물, 세차 진행·리뷰 흐름도.

02

와이어프레임

키오스크 회색조 레이아웃: 코스 선택 → 차종·부착물 → 옵션 → 주문 확인.

03

키오스크

키오스크 화면: 코스 선택, 주문 확인·결제, 결제 방식, 결제 완료, 차량번호 자동 인식.

04

앱 컨셉

메인 화면 대안 두 가지: 차량 상태를 먼저 보여 주는 안, 예약 현황을 먼저 보여 주는 안.

05

앱 디자인

사용자 앱 전체 흐름(메인 → 매장 → 예약 → 결제 → 고객센터 → 내 정보)과 주요 화면.
