Case 04 / 07

동서식품

커피머신 연결부터 취향에 맞는 추출과 사용 리포트까지 이어지는 앱을 설계했습니다.

역할
PM ⁠·⁠ 기획⁠·⁠디자인 리드
범위
모바일 앱 ⁠·⁠ 머신 연결⁠·⁠제어 ⁠·⁠ 커피 추출⁠·⁠사용 리포트
기간
작성 예정
결과
작성 예정

PROBLEM

커피머신의 첫 연결부터 추출과 사용 기록 확인까지 앱에서 이어져야 했습니다.
블루투스⁠·⁠Wi-Fi 연동 중 이탈을 줄이고, 선호 설정과 사용 리포트를 활용하도록 설계해야 했습니다.

DECISION

연동을 기기 검색⁠·⁠네트워크 선택⁠·⁠비밀번호 입력으로 나누고, 실패 안내와 성공 화면을 설계했습니다.
추출은 저장 설정을 쓰는 빠른 추출과 직접 설정하는 방식으로 구분했습니다.

OUTCOME

메뉴 구조와 와이어프레임을 정리하고, 머신 연동의 성공⁠·⁠실패 화면을 디자인했습니다.
메인⁠·⁠절전⁠·⁠커피 추출⁠·⁠완료 평가⁠·⁠사용 리포트⁠·⁠머신 관리 화면까지 구체화했습니다.

PROCESS

01

PRD

커피 머신 연동 앱 제품 요구사항 정의서: 목표⁠·⁠일정, 메뉴별 상세 기능.

02

와이어프레임

와이어프레임 전체: 홈, 연동/관리, 추출하기, 리포트, 더보기.

03

컨셉

4차 컨셉: 머신만 깔끔히 보이는 상단, 아이콘 동그라미 있는⁠·⁠없는 버전 비교.

04

머신 연동

연동 시작 → 블루투스⁠·⁠Wi-Fi 검색 → 목록 → 비밀번호, 연결 실패 안내와 연결 성공 화면.

05

디자인

전체 디자인: 메인⁠·⁠절전, 커피 추출(빠른⁠·⁠직접⁠·⁠완료 평가), 나의 커피 리포트, 머신 관리, 알림, 더보기.
