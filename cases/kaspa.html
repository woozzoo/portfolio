Case 06 / 07

카스파

세차장 이용객 연령대를 고려해, 복잡한 혜택이나 프로모션보다 세차라는 본래 목적에 집중한 직관적이고 큰 화면으로 설계했습니다.

역할
기획⁠·⁠디자인 1인 전담
범위
세차장 키오스크 ⁠·⁠ 사용자 앱 ⁠·⁠ 파트너⁠·⁠관리자 화면
기간
2023.09 ~ 2025.01
결과
고객 승인⁠·⁠납품 완료 ⁠·⁠ 앱 스토어 출시 ⁠·⁠ 실제 매장 운영

PROBLEM

고객사는 앱에서 세차 예약과 이용권 판매를 제공하려 했습니다.
매장 키오스크의 현장 이용과 앱의 사전 예약을 함께 설계하면서, 구매 방식과 선택 단계를 정리해야 했습니다.

DECISION

보유권 예약과 신규 1회권 구매를 별도 경로로 설계했습니다.
키오스크는 차량번호 자동 인식을 반영하고, 코스⁠·⁠차종⁠·⁠부착물 선택에서 결제로 이어지는 과정을 단순화했습니다.

OUTCOME

키오스크와 사용자 앱의 기획⁠·⁠디자인을 1인 전담해 고객 승인과 납품을 마쳤습니다.
앱 스토어 출시와 실제 매장 운영으로 이어져, 예약과 현장 세차에 쓰이는 서비스로 구현됐습니다.

PROCESS

01

흐름 설계

회원가입⁠·⁠로그인, 세차권 구매⁠·⁠예약, 차량 등록, 선물, 세차 진행⁠·⁠리뷰 흐름도.

02

와이어프레임

키오스크 회색조 레이아웃: 코스 선택 → 차종⁠·⁠부착물 → 옵션 → 주문 확인.

03

키오스크

키오스크 화면: 코스 선택, 주문 확인⁠·⁠결제, 결제 방식, 결제 완료, 차량번호 자동 인식.

04

앱 컨셉

메인 화면 대안 두 가지: 차량 상태를 먼저 보여 주는 안, 예약 현황을 먼저 보여 주는 안.

05

앱 디자인

사용자 앱 전체 흐름(메인 → 매장 → 예약 → 결제 → 고객센터 → 내 정보)과 주요 화면.
