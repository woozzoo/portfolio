Case 07 / 07

두잇

급식기⁠·⁠급수기 2종의 장애 상황별로 인식과 조치가 쉽도록 흐름을 설계하고, 반려동물과의 일상 기록이 자연스럽게 쌓이는 구조로 구축했습니다.

역할
PM ⁠·⁠ 기획⁠·⁠디자인 리드
범위
급식기⁠·⁠급수기 연동 모바일 앱 ⁠·⁠ 반려동물 등록⁠·⁠리포트⁠·⁠건강 기록
기간
2025.01 ~ 2026.01
결과
작성 예정

PROBLEM

급식기와 급수기를 한 앱에 연결하고 반려동물의 일상 기록을 함께 다뤄야 했습니다.
기기 연결 상태와 네트워크⁠·⁠사료 인식 오류에 따라 서로 다른 화면과 안내가 필요했습니다.

DECISION

기기가 없을 때⁠·⁠일부 연결됐을 때⁠·⁠모두 연결됐을 때로 메인 화면을 나눴습니다.
Wi-Fi 선택⁠·⁠DNS 설정⁠·⁠사료 인식 중 발생하는 오류를 구분해 안내 화면을 설계했습니다.

OUTCOME

메뉴 구조⁠·⁠기능명세⁠·⁠와이어프레임을 정리하고, 연결 상태별 메인 시안을 확정했습니다.
기기 연결⁠·⁠사료 인식 오류 안내와 반려동물 등록⁠·⁠리포트⁠·⁠건강 기록 화면을 디자인했습니다.

PROCESS

01

메뉴 구조

앱 메뉴구조도 ver.2.

02

기능명세 ⁠·⁠ 와이어프레임

기능명세서 와이어프레임 → 와이어프레임 1차 → 2차 기획(메인).

03

컨셉

메인 확정 시안: 기기 연결 후⁠·⁠기기 없음⁠·⁠모두 연결.

04

기기 연결

연결 시작 → Wi-Fi 선택 오류 → DNS 변경 오류.

05

사료 인식

사료 인식 준비, 움직임 감지 오류 안내. (재시도⁠·⁠인식 성공 화면은 미수집)

06

디자인

전체 디자인: 우리 아이 등록, 데일리 리포트, 샵, 발도장, 미션, MY, 건강 기록, 로그인.
