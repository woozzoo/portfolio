Case 03 / 07

솔루엠 SOLNET

권한별로 고객·장치·콘텐츠를 관리하는 디지털 사이니지 콘솔을 설계했다.

역할
PM · 기획·디자인 리드
범위
슈퍼관리자·파트너·사용자 콘솔 · 장치·콘텐츠·라이선스 관리
기간
2024.02 ~
결과
작성 예정

PROBLEM

슈퍼관리자·파트너·사용자가 서로 다른 권한으로 고객·장치·콘텐츠를 관리해야 했다. 계정 구조와 라이선스 조건을 반영한 콘솔 설계가 필요했다.

DECISION

계정과 메뉴 접근 범위를 권한별로 나누고, 고객·장치·콘텐츠·라이선스 업무를 구분했다. 섹션별 확정사항을 화면별 기능 정의와 관리 흐름에 반영했다.

OUTCOME

메뉴·계정·라이선스 기준을 기획 문서로 정리하고, 화면별 기능을 정의했다. 고객·장치·콘텐츠 목록부터 장치 상세·스케줄·라이선스까지 콘솔 화면을 디자인했다.

PROCESS

01

메뉴 구조

최초 메뉴구조도(SAC).

02

IA

3차 섹션별 기획 확정사항: 메뉴 확정 항목, 계정 구조, 라이선스.

03

흐름도

관리자 콘솔 흐름도.

04

기능 정의 · 와이어프레임

ASAC 포함 최종 기획: SAC·RMS·CMS 화면별 기능 정의와 2·3차 확정 사항.

05

콘솔 디자인

로그인, 고객 관리, 장치 관리(PAC), 콘텐츠 목록, 장치 상세·스케줄, 라이선스, 장치 관리(ASAC/RMS).
